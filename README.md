# 榆灯镇：小镇社会模拟器

一个可暂停、可观察、可反复生成世界的单机社会模拟器原型。居民有自己的性格、能力、职业、目标、记忆与关系；每轮同时选择行动，由小镇规则结算生活、经济、家庭、建设和冲突。

## 启动

在项目目录开两个终端：

```sh
python3 -m http.server 4173
python3 backend.py
```

浏览器打开 `http://localhost:4173`。后端连接时会把多个小镇存入 `data/towns.json`；后端离线时仍可用浏览器本地存档。

随机创建世界默认使用本地生成，不需要 API 密钥。启用大模型初始化时，在启动后端的终端环境中设置 `OPENAI_API_KEY`，可选设置 `OPENAI_MODEL`，然后重启后端：

```sh
export OPENAI_API_KEY="你的新密钥"
export OPENAI_MODEL="gpt-6-astra"
python3 backend.py
```

密钥只由本机后端读取，不放在前端代码或浏览器存储中。不要把密钥提交到项目或贴进聊天记录；之前若曾经贴出过密钥，请先在提供方撤销并轮换。

## 当前可玩内容

- **逐轮生活模拟**：居民根据个人需求、性格、能力和目标选择工作、吃饭、休息、交往、学习、照料、经营、建设或冒险；模拟时间映射为更快的人生阶段。
- **角色能力与成长**：力量、速度、魅力、智力、情商、财商等基础属性，加上与职业和爱好对应的熟练度。日常行动与成长阶段会提升对应能力；属性变化会更新角色档案和系统设定。
- **具体目标与利益冲突**：目标可以指定到某个地块。两名居民争夺同一格时会产生记恨、好感下降、报复或犯罪风险；角色也会在目标完成后自行选择新目标。
- **随机建镇**：点击“随机创建世界”会新增一个独立世界，不覆盖当前小镇。没有服务端模型配置时使用本地随机生成；模型可用时会生成背景、环境、混合立场的成年居民及少量额外设施。
- **可选的大模型世界初始化**：本机后端通过 OpenAI Responses API 和受约束的 JSON Schema 生成世界资料。页面展示整批调用的 token 总量，并按角色背景长度估算分摊；估算会明确标注。
- **逐居民大模型回合决策**：点击“AI 回合”可开启。每位居民使用自己的系统提示词、角色背景、能力、记忆、关系和可用工具；模型只能从游戏规则生成的候选行动里选一个，游戏本地结算行动结果。每轮最多并发 4 位居民的请求，失败角色回退到本地策略；居民档案显示实际调用数与 token 用量，小镇概况显示累计用量。逐回合调用会产生 API 费用，默认关闭。
- **多镇存档与地图**：创建、切换多个小镇；区域可扩展为 6×4、8×5 或 10×6。角色可以购买具体地块，建筑可升级，建筑占地形状和方向会随设施等级变化。
- **居民自己推动建设**：玩家不能指定公共设施的类型和位置，也不能代替居民发起建设。公职人员和居民会按需求提出公共设施方案；居民投票超过三分之二通过后，由居民施工，费用从镇公所预算支付。常驻“居民提案与投票”面板显示提案内容、预算、选址、逐人票态和历史结果。私人购地、建房、开店和扩张由居民按目标和资金自行决定。
- **治安与司法**：欺诈、威胁、殴打、谋杀和破坏可能由居民的私怨、债务或利益冲突触发。案件依次经历警方调查、检察审查、法院判决和监狱执行；角色会留下刑期、健康、道德与关系变化记录。生活水平持续下降也可能引发抗议。
- **住房、食物与经济**：公租房有固定容量并按月收租；私人房屋可以买卖和出租，店铺可开分店或加盟。工资以人民币结算并缴税；没钱无法消费，饱腹为零会损害健康，健康为零会死亡。居民可向愿意出借的人申请有记录、可计息的借款。
- **家庭与离婚**：角色可以结婚、生育并查看家庭成员。家庭面板汇总成员现金、私人房产、店铺品牌、对外债权与欠款。离婚预览会列出现金分配、各处房产和品牌归属估值、抚养安排；私有房产和品牌按估值尽量平分，无法拆分的差额以无息结算债权平衡。孩子依据依恋、日常照料、安全感与年龄表达的意愿决定主要跟哪位家长生活，另一位仍保留亲子关系。
- **关系、记忆和故事**：角色有丰富背景、MBTI、星座、心情、阴暗面和道德值。玩家可查看行动日志、想法、关系互动和角色提示词；居民可通过亲历、附近九宫格、电话和电视获取消息，短期记忆会压缩，完整历史仍保存并可主动回想。
- **环境与健康**：道路、土壤、物价、洪水、寒潮、流感、罢工、盗窃和经济衰退影响生活。健康会随时间、疾病、饥饿与居住条件变化；居民会自行决定休息、求医或帮助他人。

## 观察与控制

- “推进一轮”让所有居民基于同一轮的世界信息行动，再统一结算。
- 点击居民查看能力、目标、想法、行动日志、背景、记忆、关系和个人账本。
- 点击建筑和地块只查看等级、服务、容量、工作人员、居民、产权与位置。公共和私人建设均由居民自主决定；“居民提案与投票”面板用于旁观逐人表决和历次结果。
- “随机创建世界”保留旧世界并切换到新世界；“小镇列表”用于返回其他存档。
- “治安与司法”可查看机构建设状态、社会不满和案件进度。

## 架构与边界

- `index.html`、`styles.css`：单页界面。
- `app.js`：世界状态、居民策略、回合结算、关系、家庭、资产、建设与事件。
- `backend.py`：仅监听本机地址的多小镇 JSON REST 服务，并代理服务端大模型初始化请求。
- `backend-client.js`：前端存档、服务端连接和本地回退。

这是单机原型，不是多人网游后端。当前后端使用本机 JSON 文件；账号、远程 API Key 管理、数据库迁移和联网多镇同步仍属于后续工作。大模型功能必须在后端设置 `OPENAI_API_KEY`；本机没有配置密钥时，世界初始化使用本地随机生成，NPC 使用本地策略。
